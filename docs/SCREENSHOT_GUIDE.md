## Recommended use in the assignment

**Q3: Interaction and dialogue design:** figures 1, 2, 7, 9, and 10 help demonstrate discoverability, the five intents, guided responses, and navigation. The screenshots support—but do not replace—the required interaction model, utterance table, and flowchart.

**Q4: Prototype implementation:** figures 1–12 show the UI, inputs, complaint lifecycle, error handling, visible feedback, confirmation, support workflows, and mobile adaptability.

**Suggested smaller screenshot set for the 2,000–3,000-word report:** figures 1, 2, 3, 4, 5, 6, 8, 9, 10, 11, and 12. Put any extra figures in an appendix.

**Notes to report-writing partner:**
- Use these as *prototype evidence*, not proof of real bank integration or user testing.
- The chatbot does not contact a real bank, reverse funds, or connect to a live employee.
- Add actual user testing consent forms, task outcomes, times, and feedback separately, after participants complete tasks.
- Refer to each image by its figure number when discussing Nielsen's visibility of system status, error prevention, user control and freedom, and recognition rather than recall.
